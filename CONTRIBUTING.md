# Contributing

Welcome: fixes, translations, installation reports, readable labels and synthetic parser fixtures.

Open an issue with the app version, OS/Python versions, a minimal reproduction and expected behavior. Replace every task name, path, account identifier and count with fictional examples. Never attach session logs, credentials, private screenshots, personal contact information, student/customer material or internal prompts.

For a pull request, keep the change focused and run `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -p 'test_*.py'`. Use demo mode for screenshots. Do not add telemetry, model calls, unsolicited integrations, star manipulation or unrelated features.
